# RAYA Cyclone Intelligence

An independent engineering project under the larger RAYA Climate Intelligence platform.

## Mission

Develop a cyclone intelligence system for historical analysis, storm tracking,
intensity analysis, geospatial exposure assessment and future forecasting research.

## Initial Geographic Scope

Bay of Bengal and the North Indian Ocean.

## Technology

- Python
- Pandas and NumPy
- Streamlit
- Plotly and PyDeck
- GeoPandas and Shapely
- Scikit-learn (future forecasting research)

## Data Sources

- NOAA IBTrACS
- India Meteorological Department (IMD)

## Development Status

Phase 0: Environment setup completed.
Phase 1: Project architecture initialization.
Phase 2: Historical cyclone data foundation (upcoming).

## Important

This is a research and decision-support project, not an operational
meteorological warning service.
