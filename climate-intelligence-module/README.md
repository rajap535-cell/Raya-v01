# Regional-Climate-Intelligence-and-Forecasting-System-for-Kolkata

##  Overview

This project is an interactive Climate Intelligence and Forecasting System developed for the Kolkata region using historical weather data.

The system analyzes climate behavior, detects environmental anomalies, visualizes weather trends, and predicts future climate conditions using forecasting models.

---

#  Features

✅ Temperature Trend Analysis  
✅ Humidity Analysis  
✅ Wind Speed Analysis  
✅ Cloud Cover Analysis  
✅ Sea Level Pressure Analysis  
✅ Heat Alert Detection  
✅ Rainy Days Analysis  
✅ Monthly Climate Trends  
✅ Forecasting using Prophet  
✅ Interactive Streamlit Dashboard  
✅ Environmental Insights  

---

#  Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- Prophet
- GitHub

---

#  Dataset

Dataset used:
- Kolkata Weather Dataset (2017–2022)

Dataset contains:
- Temperature
- Humidity
- Wind Speed
- Pressure
- Cloud Cover
- Weather Conditions

---

#  Forecasting

The project uses Facebook Prophet for:

- Temperature Forecasting
- Humidity Forecasting

The forecasting system predicts future environmental patterns and seasonal climate behavior.
